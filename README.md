## 📊 EV Analysis Dashboard (Power BI)

This project includes an interactive dashboard built using **Power BI** to analyze Electric Vehicle (EV) trends across different dimensions such as model year, manufacturer, state distribution, and fuel eligibility.

---

### 🚀 Dashboard Overview

The dashboard provides a complete analytical view of EV adoption:

* **Total Vehicles:** 150.42K
* **Average Electric Range:** 67.83
* **BEV Vehicles:** 117K (78%)
* **PHEV Vehicles:** 34K (22%)

---
 
### 📈 Key Visualizations

1. **Model Year Trend**

   * Displays growth of EV adoption over time
   * Shows a sharp increase in recent years (peak ~75M)

2. **Geographical Distribution**

   * Map visualization of total vehicles by state
   * Helps identify high adoption regions

3. **Top Manufacturers**

   * Tesla leads significantly
   * Followed by Nissan, Chevrolet, Ford, BMW

4. **CAFV Eligibility**

   * Donut chart showing:

     * Eligible vehicles
     * Not eligible vehicles
     * Clean alternative category

5. **Top Models**

   * Most popular EV models:

     * Model Y
     * Model 3
     * Leaf
     * Model S
     * Bolt EV

---

### 🎛️ Filters Available

* City
* Electric Utility
* EV Type

These filters allow dynamic exploration of the dataset.

---

### 🛠️ Tools & Technologies

* **Power BI** – Dashboard & Visualization
* **Python (Pandas, Matplotlib)** – Data Processing
* **CSV Dataset** – Source Data

---

### 📌 Insights

* EV adoption has grown exponentially after 2018
* Tesla dominates the EV market share
* Majority vehicles are **Battery Electric Vehicles (BEVs)**
* Certain states show significantly higher adoption rates
